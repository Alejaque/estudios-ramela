# Reina-Valera 1909, texto offline

Fuente: https://github.com/BibleAquifer/ReinaValera1909
Licencia declarada por la fuente: dominio público, CC0.

El JSON local conserva el texto de los versículos de los 66 libros. Se quitaron únicamente etiquetas HTML y números de versículo en superíndice, convertidos en claves; se decodificaron entidades HTML. No se modernizó la ortografía.

La app incluye el texto completo en su paquete precargado para no depender de red al consultar pasajes. La primera descarga o actualización completa requiere conexión.
